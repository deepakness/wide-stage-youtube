# Wide Stage for YouTube

Press `` ` `` on a YouTube video, or click the wide stage button next to the fullscreen button in the player, to fill the browser tab with the player. Do it again to go back to the normal page. The video keeps its aspect ratio, so it fills the screen when the shape matches and shows bars when it doesn't.

https://github.com/user-attachments/assets/26598d4e-1c75-4825-a4fe-af2384269a98

## Install

1. [Download the latest ZIP](https://github.com/deepakness/wide-stage-youtube/archive/refs/heads/main.zip). You can also clone it with `git clone https://github.com/deepakness/wide-stage-youtube.git`.
2. Unzip the file. You should get a folder named `wide-stage-youtube-main` with `manifest.json` in it.
3. Open `chrome://extensions` in Chrome.
4. Turn on **Developer mode** in the top right.
5. Click **Load unpacked** and select the unzipped folder.

Open any YouTube video and press `` ` ``. Keep the folder where it is. Chrome loads the extension from it, so moving or deleting it breaks the extension.

## Update

After editing the code, click the reload icon on the extension card in `chrome://extensions`, then refresh the YouTube page.
